# Fontes visuais

`creation-art.jpeg`: ilustração da página 10 do Livro Básico de Wilderfeast fornecido no projeto, extraída sem redesenho.
`cover-art.jpeg`: ilustração da capa do mesmo PDF, extraída sem os textos sobrepostos da capa.

Essas ilustrações pertencem aos respectivos titulares do livro e não são abrangidas pelas licenças do código do módulo. Os arquivos SVG de decoração foram produzidos para este módulo, inspirados nas referências fornecidas. A moldura chapter-frame.svg segue o tratamento gráfico do título Criação de Personagens.

Os ícones de Utensílios e as ilustrações de receitas em assets/compendium foram extraídos do mesmo Livro Básico (p. 14–19 e 79–84). Permanecem sob os direitos dos titulares do livro.

Variantes monster-* são SVGs da mesma família gráfica, recoloridos em verde/vermelho/branco para o tema dos monstros. O retrato padrão monster-cute.svg é uma ilustração vetorial própria do módulo.
